# GOMI MONI

A trash game, about trash, for the [Society of Play](https://societyofplay.itch.io/) [Pompous Trash Jam 2025](https://itch.io/jam/pompous-trash-2025).


## Description

Gomi in the hole.
Moni in the pocket.
Moni buys trash.
